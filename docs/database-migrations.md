# Database Migrations

## Tool

Migrations are managed by Alembic. The configuration is in `alembic.ini` and `alembic/env.py`.

## Conventions

- UUID primary keys are generated by `uuid.uuid4`.
- Every table has `created_at` and `updated_at` columns.
- Soft delete is supported via an optional `deleted_at` column.
- Indexes are added for lookup fields such as `email` and `role_id`.

## Running Migrations

```bash
cd apps/api
alembic upgrade head
```

## Creating a New Migration

```bash
alembic revision --autogenerate -m "describe change"
```

Verify the generated migration before committing it.
